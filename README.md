# シューティングゲーム 企画・技術検討（00001_shooting-game）

## 1. 概要
本フォルダは、シューティングゲーム（STG）の企画立案、ゲームデザイン、手触り（ゲームフィール）の検証、およびプロトタイプ制作を行うための検討ワークスペースです。

## 2. 検討アジェンダ・構成要素

### 2.1 ゲームスタイル・方向性の検討
- **スクロール形式**: 縦スクロール（縦STG）/ 横スクロール（横STG）/ 全方位（ツインスティック等）/ 固定画面（インベーダー系）/ 3D
- **ゲーム性・難易度帯**:
  - クラシック・スコアアタック系（パターン構築、爽快感）
  - 弾幕STG（微細な当たり判定、弾幕回避の美学）
  - ローグライトSTG（ヴァンサバライク、強化ビルド構築）
  - カジュアル・ミニゲーム系（手軽に短時間で遊べる設計）

### 2.2 コアループ・基本メカニクス
- **攻撃**: 通常ショット、タメ撃ち、ボム（緊急回避・全画面攻撃）、近接攻撃など
- **回避・防御**: かすり（Graze）、シールド、ダッシュ無敵時間
- **リソース・リスク＆リターン**: 敵に近づくほど高得点、リスクを冒してパワーアップ取得など

### 2.3 プログラミング・技術要件
- 自機の操作感（慣性、加減速、低速移動モード）
- 弾幕・弾丸道（サイン波、放射状、狙い撃ち弾、ホップ）
- 当たり判定アルゴリズム（円同士の判定、AABB、レーザー判定）
- パフォーマンス最適化（オブジェクトプールによる弾丸の再利用）
- 実行環境（ブラウザで即動く HTML5 Canvas / Phaser / Godot / Unity など）

## 4. 開発ロードマップ（フェーズ定義）

今後の開発を見通しよく進めるため、以下の 5 段階でステップを定義します。

| フェーズ | テーマ | 主な実装内容 | ステータス |
| :--- | :--- | :--- | :--- |
| **Phase 1** | **基盤 ＆ 基本ループ** | Vite + React + TS + Tailwind 環境構築、タイトル画面、HUD、自機操作、オートショット、敵ドローン出現、基本SE | 完了 |
| **Phase 2** | **戦闘 ＆ 被弾・リトライ** | 敵の狙い撃ち弾、複合円当たり判定、シールドHP・残機・無敵時間、カメラシェイク、ゲームオーバー画面 | 完了 |
| **Phase 3** | **武器強化 ＆ 緊急回避** | パワーアップアイテム、3系統武器（5段階強化）、HUD武器表示、緊急回避ボム（`Space`/`B`/ボタン）、スピードアップ | 完了 |

| **Phase 5** | **演出 ＆ サウンド・難易度** | プロローグ（HUDブリーフィング）、難易度選択（Easy/Normal/Hard＋撃ち返し弾）、Web Audio シンセBGM（通常/ボス） | 完了 |
